# ClearDay 0.3

Мобильный MVP ежедневного планировщика.

- быстрый ввод задач;
- Top-3 фокус;
- выполнение и удаление;
- простое автоматическое определение приоритета;
- утренний и вечерний сценарии;
- сохранение в браузере через localStorage;
- адаптивный интерфейс.

Откройте `index.html` для запуска.

Следующий этап: backend, аккаунты, синхронизация, настоящий AI-разбор текста, голосовой ввод, напоминания и Pro-версия.
